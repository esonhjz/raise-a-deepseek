# 养一只大肥鱼

一个采用 MIT 许可证的 AI 伙伴项目：从最基础的设定开始，通过日常相处、教她做事和共同开发，逐渐丰富她的记忆、个性和能力。本仓库提供逐步提取的通用模块和离线示例，尚未发布 npm 包。

不是聊天机器人模板，也不是角色卡集合。它关心的是：一个角色怎样在真实相处里慢慢长出来，以及这些经历怎样留下来。

当前进度见 [docs/STATUS.md](docs/STATUS.md)（2026-10-30）：私有陪伴部署已实现保守的自然聊天经历捕获、单条/主题遗忘及统一恢复工具首版，M1 仍待真实体验验收。本仓库提供独立的 SQLite 记忆核心，包含事务写入、revision 冲突保护和可选 FTS5 候选检索；本次更新同步进度与[恢复设计](docs/RECOVERY.md)，不包含私有时间线和恢复工具代码。提取范围见 [docs/EXTRACTION.md](docs/EXTRACTION.md)。

## 三个原则

**从基础设定开始。** 初始设定只回答“她是谁、怎么说话、边界在哪”。剩下的性格，靠日子里发生的事长出来，不靠一次写两千字。

**相处不是投喂。** 她会拒绝、会改期、会自己找事做。共同开发是相处的一部分：一起改一个功能、一起看一段代码、一起把一个想法做成能跑的东西。

**记忆不只是检索。** 记住是为了让下一次对话能接上，而不是把历史全塞进上下文。原始记录留在磁盘上，进模型的只有当下需要的一小段。

## 快速开始

需要 Node.js 24 或更高版本（本轮在 24.18.1 验证）。使用内置 `node:sqlite`，无需安装依赖或填写模型凭据。

```bash
npm run init          # 建一个家：data/home
npm run letter -- --to her --text "今天开始，这里就是你的家。"
npm run check         # 看两个方向有没有未读
npm run recall -- --query "家" --key home
npm test              # 全部离线测试
npm run demo:memory   # 合成数据：SQLite 保存、纠正、重开与遗忘
npm run check:public  # 检查拟公开文件中的常见敏感内容
```

`npm run init` 会创建：

```
data/home/
  letters/          写给她的信
  replies/          她写回的信
  room/             她敲门的留言
  diary.md          日记
  growth.md         成长记录
  memory/           每个联系人的记忆库
```

跑起来之后，把 `src/` 接进你自己的 DSH 宿主：角色卡、记忆、信箱、时间这些模块都可以单独用。

SQLite 示例在系统临时目录运行并自行清理，不读取真实聊天。接入说明与已知限制见 [SQLite 记忆](docs/SQLITE-MEMORY.md)。

## 记忆怎么工作

三层，各管一件事：

1. **记忆库**：她自己决定记什么。一条只写一件事，有状态（候选、确认、取代、删除）和来源。召回按中文双字词匹配，命中任意一个有意义的词就带出来。
2. **对话档案**：每轮真实对话原样追加到 JSONL，不进模型。要查旧事时按词检索，只带 3 条、400 字以内。
3. **上下文交接**：上下文刷新前，把最后三轮原样打包；新上下文开头带着它，等新的对话接上。

遗忘和取代已有基础实现；旧日志压缩、墓碑索引和长期多角色记忆还没做。日志只增不删，方便以后设计压缩和删除。

新增的 `SqliteMemoryStore` 使用同一目录下的 SQLite 保存多个联系人的独立记录，支持 `superseded` 状态、事务化修改与 revision 冲突检测。它是独立 API，不会自动替换原 `MemoryStore` 或改写已有 `default.json`。FTS5 只提供可选候选接口；默认仍使用字面召回，暂不声称检索质量优于旧方案。

## 和 DSH 的关系

DSH（DeepSeek Harness）负责跑模型、工具、权限和会话。这个仓库负责角色那一侧：

- 角色卡怎么变成系统提示
- 记忆怎么存、怎么召回
- 信箱和房间怎么送信
- 上下文刷新时怎么交接

仓库里没有 QQ 连接器、桌宠界面、只读旁观视图，也没有任何账号凭据。那些属于各人的私有部署，不属于这个项目。

## 还没有

- 真正跑起来需要你自己的 DSH 宿主和模型凭据
- 本仓库没有 UI、QQ/微信连接器
- 本仓库尚未提取自动日记、完整经历时间线、联网、图片发送和统一恢复工具
- 私有部署的日记长期质量、情绪状态、完整经历时间线和每周回顾尚未完成
- 主动消息、群聊、语音
- 尚未发布 npm 包，也不是开箱即用的完整 QQ 机器人

## 隐私

`data/`、`.local/`、`.env` 都不进 Git。角色卡、真实聊天、账号 ID、凭据都不应该出现在仓库里。示例卡是合成的，不是任何人的真实角色设定。
