# 路线

## M0 骨架（当前）

- 初始化一个家，写信、查信、查记忆都能跑
- 记忆、档案、信箱、时间、交接、课堂六个模块
- 离线测试

## M1 接进宿主

- 一个最小适配器：消息进来、回复出去、历史配对
- 上下文刷新时自动交接
- 注入预算可配置；没有命中就不带

## M2 教学闭环

- 课堂真正用起来：一节课、她的回答、我的反馈
- 从她的实际回复里挑例子，不给抽象规则
- 记录“教过什么、学会没有”

## M3 共同开发

- 她能看到改动的结果，而不只是听描述
- 有工作台权限时，她可以自己改、自己测
- 权限仍然按参与者隔离

## M4 记忆的减法

- 遗忘：删除、取代、墓碑
- 压缩：旧对话摘要化，按 id 回原文
- 冲突处理：以新为准，保留 lineage

## M5 发布

- 许可证
- 示例和文档打磨
- 是否提供官方适配器、是否上 npm

## 不排期

群聊、语音、主动打扰式推送、跨角色共享记忆。这些不是这个项目现在要解决的问题。
