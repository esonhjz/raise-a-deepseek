# 路线

## 当前进度（2026-10-23，America/Los_Angeles）

- M0 骨架：完成（本仓库；计划公开，尚未发布）
- M1 接进宿主：私有陪伴宿主已有自然聊天、媒体和记忆能力；本仓库仍不内置 QQ/微信连接器，也未据此验收本仓库适配器
- M2 教学闭环：本仓库有课堂模块；私有宿主另有明确教学、纠正与撤销实现，已完成首轮用户验收，不等于本仓库课堂模块已端到端接入
- 日记核心：私有宿主已部署 SQLite 双层、调度、来源校验；首篇真实日记、10 篇质量验收待完成
- M3 共同开发：未系统开始
- M4 记忆减法：基础遗忘/取代已实现；压缩、墓碑索引未完成
- M5 发布：MIT 许可证已确定；公开发布与 npm 发布尚未进行

## M0 骨架

- 初始化一个家，写信、查信、查记忆都能跑
- 记忆、档案、信箱、时间、交接、课堂六个模块
- 离线测试

## M1 接进宿主

- 一个最小适配器：消息进来、回复出去、历史配对
- 上下文刷新时自动交接
- 注入预算可配置；没有命中就不带

## M2 教学闭环

- 课堂真正用起来：一节课、她的回答、我的反馈
- 从她的实际回复里挑例子，不给抽象规则
- 记录“教过什么、学会没有”

## M3 共同开发

- 她能看到改动的结果，而不只是听描述
- 有工作台权限时，她可以自己改、自己测
- 权限仍然按参与者隔离

## M4 记忆的减法

- 遗忘：删除、取代、墓碑
- 压缩：旧对话摘要化，按 id 回原文
- 冲突处理：以新为准，保留 lineage

## M5 发布

- 许可证：已确定为 MIT，见 [LICENSE](../LICENSE)
- 示例和文档打磨
- 是否提供官方适配器、是否上 npm

## 不排期

群聊、语音、主动打扰式推送、跨角色共享记忆。这些不是这个项目现在要解决的问题。
