# 项目目标

养一只大肥鱼：从基础设定开始，靠日常相处、教她做事和共同开发，长出一个有记忆、有个性、能力逐渐丰富的 AI 伙伴。

## 谁在做什么

- **所有者**：决定目标、方向和相处体验，给真实的反馈。
- **她**：一个持续的角色。有自己的说法、判断和拒绝；经历会留下，能力会变多。
- **宿主**（DSH）：跑模型、工具、权限和会话。它不定义角色。
- **这个仓库**：角色那一侧的机制——设定怎么生效、记忆怎么留、话怎么传、上下文断了怎么接。

## 一次完整的相处长什么样

1. **设定**：一张短卡说明她是谁、怎么说话、边界在哪。不预设性格细节。
2. **相处**：日常对话里出现偏好、约定、玩笑和分歧。
3. **教**：教一件事，让她试着做，给反馈，她改。
4. **共同开发**：一起改一个功能、看一段代码，把想法做成能跑的东西。
5. **记忆**：值得留的留下；不值得的过去。上下文刷新时，最近的经历能接上。

## 非目标

- 不做通用聊天框架，不做插件市场。
- 不靠堆角色卡制造“人设感”。
- 不把全部历史塞进上下文来假装记性好。
- 不替使用者决定她该是什么样的人。
- 不内置任何平台的账号、凭据或私有连接器。

## 判断做得好不好

看三件事，不看功能数量：

1. 她能不能说出“上次”的具体内容，而不只是“我们聊过”。
2. 她会不会在该拒绝的时候拒绝，而不是永远顺着。
3. 一起做出来的东西是不是真的能跑，而不是听起来很厉害。

## 边界

- 记忆只记录真实发生的事；没做过的、没发生的，不补写。
- 讨论过的能力不等于已经拥有；以工具和授权为准。
- 权限按参与者隔离；共享角色经历不等于公开私聊。
- 设定更新不清空共同经历。
