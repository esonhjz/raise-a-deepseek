项目当前推进到 **M1 记忆 v2 后半段**：存储迁移、检索工程和共同经历时间线首版已在私有宿主落地；时间线真实 QQ 体验尚未验收，M1 未整体完成。

## 本仓库可以复现什么

| 内容 | 代码与验证 |
| --- | --- |
| 角色卡、家、信箱、时间、交接、课堂 | 原有独立模块，离线测试 |
| JSON 记忆与对话档案 | 原有保存、候选确认、遗忘和字面召回模块 |
| SQLite 记忆核心 | 本轮提取；事务修改、revision、联系人隔离、来源和状态保留 |
| SQLite 派生 FTS5 索引 | 本轮提取；候选查询、索引维护与重建测试；默认不替代字面召回 |
| 影子观测 | 本轮提取；用条目 ID 比较结果，回调不含查询或记忆正文 |
| 合成示例与检查 | npm run demo:memory、npm test、npm run check:public |

本轮在 Node.js 24.18.1 上实跑 **27/27 项公开模块测试**，以及合成 SQLite 示例。它们不调用模型、不发 QQ 消息，也不能证明聊天人格、真实媒体或长期陪伴质量。

## 当前限制

- 生产召回仍是字面匹配。FTS5 候选实现不能解决所有同义表达、指代和历史事实问题。
- 原有 JSON MemoryStore 是简单单写者示例；需要并发写入时使用新 SQLite API。
- SQLite 纠正、主题遗忘和文本过滤仍含关键词启发式，可能误删或漏删；它们不等于完整语义理解。
- 时间线目前以明确的“记一下/记住”输入为主；不保证普通聊天中的事件都会自动记下。
- 私有时间线与记忆仍使用两套恢复清单；所有旧 archive 来源别名尚未完全覆盖。
- 日记是主观解释；来源 ID 存在不证明每个推断都正确。
- 原文或数据可因软删除保留在磁盘、QQ、服务端及备份中；召回排除不等于安全擦除。
- 本仓库不提供 QQ 连接器、DSH 会话执行器、电脑控制、自动日记、图片发送或完整时间线。
